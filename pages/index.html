📡 优选 IP 库 实时优选 · 勾选后批量测速

「服务端测速」为 Cloudflare 边缘参考延迟（CF 官方 IP 是就近值，仅供参考）；「绑定子域·浏览器实测」会把选中 IP 绑成 *.goodip.cc.cd 子域（有证书、不超时），从你浏览器测真实延迟，最适合按当前网络优选。测完点「解绑清理」删 DNS 记录。

🎯 优选 IP API 勾选 IP → 一键生成纯文本地址，填 free-bw8「自定义 IP 生成订阅链接」

每行格式 IP:端口#地区。复制上面的 URL，进 free-bw8 后台 →「优选订阅生产 → 自定义 IP 生成订阅链接」粘贴，即可一键生成订阅。

⚙️ 订阅生成 勾选的 IP → vless / trojan / clash / sing-box（含 ECH + DoH）

🔧 我的域名配优选 IP 吸收 GetCFipToDns：把优选 IP 填 DNS，让网站走 CF 优选节点

🔄 反代玩法 吸收 ymyuu/Cloudflare-Workers-Proxy

把优选 IP 用于访问目标站点：部署一个 Cloudflare Worker 反向代理（https://你的worker/目标URL），客户端把请求发往 Worker，Worker 转发到目标并原样返回。配合 ② 中的优选 IP 作为 SNI/上游，可绕开 DNS 污染。

推荐组合：客户端 →（DoH 1.1.1.1 + ECH）→ 优选 IP（③ 订阅）→ 目标站点。详见 Cloudflare-Workers-Proxy。
